    Cause: the compose project name is fixed, so the aegisnet_db_data volume from an
    earlier checkout on this machine was reused. Its roles were created by
    infra/postgres/init/01_roles.sh on first initialisation, with the passwords from
    that .env; the script never runs again. A stranger's machine has no such volume.
    Fixed in this chunk: make up now warns when the volume exists, and the README says so.
    Recovering the way the README now instructs, then continuing:
