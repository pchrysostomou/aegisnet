# Samples

Datasets that AegisNet can import. Nothing under `samples/synthetic/` or `samples/lab/` describes a real
system: every address is from an RFC 1918 or RFC 5737 range and every name is under
`example.test` or `example.com`.

| Directory | Committed | Contents |
|---|---|---|
| `synthetic/` | yes | Corpora generated by `tools/gen_synthetic_eve.py` from a fixed seed, each with a manifest |
| `lab/` | yes | One sanitised capture of **real** Suricata output from the isolated lab (`infra/lab/`, ADR-021), produced by `tools/sanitize_eve.py`, with a manifest |
| `assets/` | yes | Asset inventory seed files (`make seed`, `python -m aegisnet.cli seed-assets NAME`); upserted by hostname, confined to this directory like a dataset |
| `scenarios/` | yes | The multi-stage correlation scenario, its generator and the ground truth `make eval` scores against |
| `briefs/` | yes | The offline investigation brief served when the feature is off or unconfigured, so a checkout with no key still sees it work (ADR-031) |
| `external/` | **no** (gitignored) | Public datasets an operator fetches themselves, under their own licence terms |

## How a file gets imported

The import API (`POST /api/v1/ingest/import`, Chunk 4) accepts a **dataset id** from
[`registry.yml`](registry.yml) and nothing else. The registered relative path is resolved
under this directory; a symlink anywhere in it, a `..` component, an absolute path, a
missing or non-regular file, or a sha256 that differs from the registered one each refuse
the import (THREAT_MODEL T-1.6, `backend/tests/security/test_path_traversal.py`).

## Registry fields

| Field | Meaning |
|---|---|
| `id` | `[a-z0-9-]`, unique; what the API accepts |
| `path` | relative to `samples/`, forward slashes, no `.`/`..` |
| `manifest` | optional; the generator's manifest for synthetic corpora |
| `sha256` | of the file's bytes; verified before any line is read |
| `format` | `suricata_eve_ndjson` only in v1 |
| `licence` | licence the file is distributed under |
| `citation` | required citation text for public datasets, `null` for generated corpora; recorded on every ingest batch and printed in reports |
| `description` | one paragraph |

## Regenerating a synthetic corpus

```bash
make gen-synthetic          # byte-identical for the same seed and generator version
```

After changing the generator, regenerate, then copy the new `sha256` from the manifest into
`registry.yml`. `backend/tests/integration/test_samples_corpus.py` fails until the file,
the manifest and the registry agree.

## Adding a public dataset

1. Fetch it into `samples/external/` yourself and check its licence.
2. Convert or extract the Suricata EVE NDJSON if needed. Nothing is fetched or converted
   by AegisNet.
3. Add an entry to `registry.yml` with the sha256 and the citation the licence requires.

Packet captures and live sensor output are never committed anywhere in this repository
(`.gitignore`, pre-commit `forbid-captures`).
